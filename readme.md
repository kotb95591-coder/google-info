# google-info
Repo containing detailed information about Google


Google – это американская многопрофильная компания, специализирующаяся на поисковых системах, онлайн‑рекламе, облачных сервисах и прочих технологических продуктах. Она была основана Ларри Пейджем и Сергеем Брином в 1998 году и быстро стала крупнейшим поисковиком в мире.
